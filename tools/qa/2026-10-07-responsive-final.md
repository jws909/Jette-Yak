# 2026-10-07 PC·모바일 글자 배치 최종 점검

## 범위

- 실제 커뮤니티 알림 도착은 사용자가 최종 확인. 기존 푸시 검증 문서에도 결과 반영
- 공통 글줄·레이아웃, 상단 알림, 날짜 선택, 앱 알림 설정
- 메인, 약 등록, 마이페이지, 캘린더, 내 약 관리, 가족 관리, 챗봇, 커뮤니티, 관리자 CSS

## 확인한 문제와 변경

1. 320px 화면에서 body의 최소 너비와 세로 스크롤바가 충돌하던 부분 해제. 가로 넘침을 숨기는 대신 flex/grid 자식의 최소 폭을 조정
2. 모바일 메인 약봉지에서 제목·체크박스·버튼이 한 줄을 차지해 이름이 몇 글자씩 꺾이는 문제 수정. 작업 버튼을 별도 행으로 배치
3. 태블릿은 왼쪽 메뉴가 차지한 폭까지 고려해 카드와 상담 열을 전환
4. 900px 약 등록 화면에서 긴 영양제 탭이 오른쪽으로 넘치던 문제 재현 후 3열 그리드·자연 줄바꿈으로 수정
5. 약 이름·분류·처방 정보·작성자·댓글·계정 정보의 긴 텍스트 줄바꿈과 행간 정리
6. 알림 팝오버를 모바일 화면 안에 고정하고 탭·동작 버튼의 줄바꿈 허용
7. 작성·상세·설정 모달의 높이와 스크롤 영역 정리. 날짜 입력의 아이콘 옆 최소 폭 해제

## 검증

환경: Vite production build, http://127.0.0.1:4173, 별도 브라우저 체험 세션.

| 화면 크기 | 확인 범위 | 결과 |
| --- | --- | --- |
| 320px | 주요 8개 페이지, 긴 제품명 검색, 내 약 목록 | 최종 확인한 문서 가로 폭과 스크롤 폭 일치 |
| 390px | 실제 약봉지 펼침, 커뮤니티 작성 모달, 약 주의 모달, 상담기록 전체 삭제 확인창 | 글자·버튼 겹침 없이 표시. 긴 작성창은 내부 스크롤 가능 |
| 768px·1024px | 약 등록·캘린더·내 약 관리·챗봇·커뮤니티 | 문서 가로 넘침 없음 |
| 900px | 주요 8개 페이지 | 약 등록 탭 보정 후 가로 넘침 없음 |
| 1440px | 주요 8개 페이지 | 가로 넘침 없음. 챗봇 상담 입력 영역까지 화면 안에 표시 |

- 약 등록의 처방전 분류 텍스트와 900px 탭은 첫 검사에서 발견해 추가 수정·재빌드·재확인
- 시간대 탭처럼 의도한 내부 가로 스크롤은 유지
- 모달은 전체 삭제 확인창의 취소까지만 실행. 실제 기록 삭제·약 등록·댓글 작성 없이 UI 확인
- 프런트 자동 테스트 151개, 흐름 검사 80개 통과. ESLint 통과
- 최종 production build 통과, CSS 파싱과 git diff --check 통과
- 검증 탭 콘솔 오류·경고 없음

## 검증 한계와 반영

브라우저 너비 검사는 iOS·Android 실기기 검사와 다르다. 관리자 화면은 CSS와 구조를 검토했으며 이번 체험 세션에서는 관리자 계정 화면을 열지 않았다. 기존 단일 JS 번들의 크기 안내는 빌드에 남아 있다.

현재 preview가 읽는 dist까지 새로 빌드했다. 기존 설치 앱에서는 새 버전 안내의 업데이트를 적용한 뒤 확인한다.
